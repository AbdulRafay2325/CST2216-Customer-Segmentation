# Mall Customer Segmentation

This project is a modularized version of the Week 11 Unsupervised Clustering notebook for the CST2216 Individual Term Project.

The application uses K-Means clustering to segment mall customers using age, annual income, and spending score.

## Features

- Loads the Week 11 `mall_customers.csv` dataset
- Validates customer data
- Standardizes clustering features
- Evaluates multiple cluster counts
- Uses silhouette score to recommend k
- Trains a K-Means clustering model
- Displays an interactive cluster visualization
- Displays cluster profiles
- Assigns new customers to clusters
- Includes logging and error handling
- Includes automated tests
